# Сервис сокращения ссылок

Простой REST API сервис на Go для создания коротких ссылок, редиректа и сбора статистики переходов.

## Возможности

- Создание короткой ссылки по длинному URL (POST /links)
- Редирект по короткой ссылке (PATCH /links/{title})
- Получение статистики переходов по ссылке (GET /links/{title})
- Получение списка всех сохранённых ссылок (GET /links)

## Технологии

- **Go** (`net/http`, `gorilla/mux`, `pgx`)
- **PostgreSQL** (миграции, CRUD операции)
- **Docker** и **Docker Compose**
- **Makefile** для автоматизации задач
- Переменные окружения (`.env`)

## Запуск проекта

### 1. Склонируйте репозиторий

```bash
git clone https://github.com/vielchelpykh/cutlink.git
cd cutlink
```

### 2. Настройте переменные окружения

Скопируйте .env.example в .env и укажите свои параметры

```bash
cp .env.example .env
```

### 3. Запустите приложение

```bash
make docker-run
```
